🏖️ Kahuna Bowl Port & Architecture Guide

🔌

Configurable Server Port

The application runs on a configurable port with multiple options:

  • Default Port: 3000
  • Environment Variable: PORT=8080 node server.js
  • Command-line Flag: node server.js --port 8080
  • Current Active Port: 3000
🏄

Quiz Bowl Rules (NAQT / ACF Style)

  • Power (+15 pts): Buzz before the power cutoff mark (*) is read.
  • Ten (+10 pts): Correct answer after power mark.
  • Neg (-5 pts): Incorrect buzz before question completes.
  • Dead Tossup (0 pts): Incorrect buzz after full tossup has been read.
  • Bonus (Up to 30 pts): 3 questions worth 10 points each.
🌴

Audio Synthesizer Engine

Built with native Web Audio API (no external downloads needed):

  • 🌊 Ocean Ambient Waves: Pink noise filtered coastal tide simulation.
  • 🔔 Tropical Marimba Chimes: Bright pentatonic scales on power.
  • 🥥 Coconut Bonk: Hollow woodblock resonance on negs.
⌨️

Keyboard Shortcuts

  • Spacebar : Buzz In (Solo mode) or Next Question
  • Enter : Submit typed answer
  • Esc / P : Pause or Resume reader
  • A / L : Team 1 / Team 2 Buzz (Hotseat)
  • 1 / 2 : Accept / Reject judge override
